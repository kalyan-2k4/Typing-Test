# Typing Test

Live App: https://my-typingg-test.netlify.app/

A lightweight, case‑sensitive typing practice web app with real‑time WPM, accuracy, typo tracking, visual on‑screen keyboard feedback, and a modern results popup.

## Features
- Real‑time Gross & Net WPM (no NaN / Infinity edge cases)
- Live accuracy & typo counter
- Exact case matching enforced
- Visual keyboard highlighting (white = correct, red = incorrect)
- Paragraph cycling + restart
- Animated metrics panel (pulse updates)
- Results modal with stats: Gross WPM, Net WPM, Accuracy, Typos, Characters, Time

## How It Works
1. Focus is automatically managed so you can just start typing.
2. Metrics update each keystroke (WPM = chars/5 per minute, Net WPM accounts for errors).
3. Case mismatch counts as an error.
4. Finish a paragraph → results popup → choose Restart or Next Paragraph.
